=== スライドインポップアップ ===

右下からスライドインするポップアップを表示します。
画像モード（バナー画像＋リンク）と、ショートコードモード（任意のHTML・
ショートコードを白いカードに表示）を切り替えて使えます。

スクロール量で表示され、×で閉じるとそのブラウザを閉じるまで再表示しません。


■ 導入手順
1. 「プラグイン」→「新規追加」→「プラグインのアップロード」→ この zip を
   選択してインストール →「有効化」
2. 「設定」→「ポップアップ」で内容を設定し、
   一番上の「ポップアップを有効にする」にチェック


■ 設定項目
   表示           : ここをオフにしている間は、どのページにも出ません
   モード         : 画像モード／ショートコードモード
   画像・代替テキスト・リンクURL
                  : 画像モードのとき。画像は「メディアから選択」で選べます
                    推奨は横幅600px以上。リンクURLが空なら、リンクなしの
                    画像として表示します
   ショートコード / HTML
                  : ショートコードモードのとき。[contact-form-7 id="123"] の
                    ようなショートコードも実行されます
   表示タイミング : ページを何%読んだら出すか
                    0＝開いた直後／30＝3割ほど読んだところ（おすすめ）／
                    50＝ちょうど半分／100＝ページの一番下
                    記事の長さがバラバラでも「どこまで読んだか」で揃います
                    ※スクロールが起きない短いページでは開いた直後に出ます
   幅（PC）       : 200〜600px。スマホでは画面幅に合わせて自動で縮みます
   表示するページ : すべてのページ／投稿ページのみ／トップページのみ
   表示するデバイス : PC・スマホの両方／PCのみ／スマホのみ
                    画面の幅で判定するので、ページのキャッシュを使っている
                    サイトでも正しく出し分けられます
   スマホとみなす幅 : この画面幅（px）以下をスマホとして扱います（既定767px）
                    既定ならタブレットは横向き＝PC・縦向き＝スマホの扱い。
                    タブレットもPC扱いにするなら小さく（例600）、
                    スマホ扱いにするなら大きく（例1024）してください
   表示バージョン : 数字を1つ上げると、一度×で閉じた人にも再表示されます
                    （中身を差し替えたときに使います）


■ 閉じたあとの挙動
   ×で閉じたことは sessionStorage に記録します。
   タブを閉じるまでは再表示しません（ブラウザを開き直すとまた出ます）。
   すぐに全員へ出し直したいときは「表示バージョン」を上げてください。


■ 自動更新
   新しいバージョンを配信すると、WordPressの「プラグイン」画面に
   「更新可能」バッジが出ます。ワンクリックで更新でき、設定内容は残ります。
   配信元: https://github.com/yoshimucom-gif/uru-kagi-popup-plugin
